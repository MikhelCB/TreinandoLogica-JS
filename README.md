# 🧠 Treino de Lógica de Programação

Este repositório foi criado com o objetivo de praticar e evoluir a lógica de programação por meio da resolução de exercícios progressivos. Os desafios são resolvidos utilizando JavaScript, com foco no desenvolvimento do raciocínio lógico e na base necessária para atuar como desenvolvedor.

---

## 🎯 Objetivo

O principal objetivo deste projeto é fortalecer fundamentos essenciais da programação, como:

- Estruturas condicionais (if/else)
- Laços de repetição (for, while)
- Funções
- Manipulação de variáveis
- Resolução de problemas
- Pensamento lógico

Além disso, o repositório serve como registro da evolução prática ao longo do tempo.
